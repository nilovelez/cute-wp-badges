# Changelog

## 1.0.0 (2026-10-30)

The first release.

- **Tools → WordPress.org Badges**, with two tabs: **My badges** reads the badges of a WordPress.org profile, and **Any badge** offers every badge in the catalog, with a search field and a filter for team badges.
- Pick badges, put them in order (drag, arrows, or sort by profile order, name or team) and get one badge or a grid, with columns, badge size and gap.
- PNG or SVG, always on a transparent background. Download the image or save it to the Media Library; SVG images only when an administrator allows them, built on the server from the plugin's own badge files.
- Each user's design is saved per tab and comes back as it was left. New badges on the profile show up marked as new, and badges gone from it are taken out, with a notice.
- Export a design to a JSON file and import it again, on the same site or another one.
- 67 badges, in the classic WordPress.org profile style, as clean SVG files.
- Deleting the plugin removes its settings, the saved designs and the profile cache.
